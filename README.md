# rl-fundamental-trading

RL-Projekt fuer Aktienhandel mit Fokus auf Fundamentaldaten und Eventeffekten (Quartals-/Jahresberichte).

## Ziel

Entwicklung und Analyse eines RL-Agenten, der Kauf-, Verkaufs- und Halteentscheidungen auf Basis von:

- Kursdaten
- Fundamentaldaten
- Ereignismerkmalen rund um Berichtsveroeffentlichungen

## Repository-Struktur

- `prototype/`: technischer Prototyp (Datenpipeline, Mockdaten, spaeter RL-Environment/Training)
- `research/`: Literatur, Notizen und Paper-Sammlung

## Einstieg

Fuer die technische Umsetzung starte mit der Prototyp-Doku in `prototype/README.md`.
