## 2. Branching from Issues

- Create a dedicated branch directly from the issue using **GitHub's built-in feature**:
  - On the issue page, navigate to the right-hand sidebar under _**Development**_.
  - Click _**Create a branch**_ (see [GitHub Docs on creating a branch for an issue](https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/creating-a-branch-for-an-issue#creating-a-branch-for-an-issue)).

- **Traceability:** Creating the branch directly from the issue automatically links the two together, which ensures clear traceability
- **Naming Format:** `<issue-id>-<issue-title>` (_this is done automatically if you use GitHub's built-in feature_)
- **Examples:**
  - `3-hybrid-model-architecture-documentation`
  - `5-add-workflow-and-branching-guidelines`

***Important note**: Avoid working directly on `main`.*
